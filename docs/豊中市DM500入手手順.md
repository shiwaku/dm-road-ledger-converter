# 豊中市 道路台帳平面図DM500 の入手手順

最終更新：2026年8月12日

検証用の道路台帳DMデータを豊中市から購入する手続きをまとめる。
データそのものの調査経緯は [検証データ調査.md](検証データ調査.md) を参照。

## 確定事項（2026年8月12日・電話回答）

| 項目 | 回答 |
|---|---|
| 郵送での申込・受取 | **可**（来庁不要） |
| 送付するもの | 申込書（様式1）＋ **返信用封筒2枚** |
| 所要期間 | **1ヶ月程度** |

### 手続きの流れ

```
1. 申込書＋返信用封筒2枚を郵送
2. 市から納付書が届く          ← 返信用封筒①を使用
3. 納付書で手数料1,500円を納付
4. CD-Rが届く                  ← 返信用封筒②を使用
```

返信用封筒が2枚必要なのは、納付書とCD-Rが別便になるため。
手数料の納付方法は「市から届く納付書で納付」と判明したので、事前に振込等を用意する必要はない。

## スケジュール

| 時期 | 内容 |
|---|---|
| 2026年8月中 | 図郭を確定し、申込書＋返信用封筒2枚を郵送 |
| 8月下旬〜9月上旬 | 納付書が届く → 1,500円を納付 |
| 9月中旬〜下旬 | CD-R到着 → 実データで検証開始 |

到着まで1ヶ月あるため、道路台帳固有の注記・記号・分類コードの検証は9月下旬以降になる。

## 未確認事項

| 項目 | 確認が必要な理由 |
|---|---|
| **図郭番号** | 申込書に記載する。決まらないと申込めない |
| 返信用封筒の指定サイズ・切手額 | 特に②はCD-Rが入る大きさが要る。不足すると差し戻しで往復ぶん遅延する |
| 押印の要否・様式の版 | 不備があると再送になり、1ヶ月がさらに延びる |
| 推奨図郭 | 記載量の多い図郭を教えてもらえるか |
| 変換結果の公開可否 | GeoJSONや画面表示例をリポジトリ・記事で出せるかが決まる |

## 図郭の選定

第一候補は **`67-68`**。同じ地図情報レベル500の道路台帳DMで図郭ごとの要素密度を測った結果、細街路密集地にあたる図郭として選んだもの。道路縁が細かく、幅員注記や側溝・マンホール等の記号が多いと見込まれる。周囲の `67-57`／`67-58`／`67-59`／`67-67` も8.1〜9.1%と一様に密なため、測定誤差に強い。

ただし図郭割図に「隣接の図郭とセットで1図郭とみなしている図郭があります」との記載があり、市の推奨があればそれに従う。

| 申込ページ | https://www.city.toyonaka.osaka.jp/kurashi/moushikomi/soshiki/moushikomi22/daicho.html |

### 書式の構成

- 日付／宛先「豊中市長　様」
- 申込者：住所・氏名（**押印欄「印」あり**）・連絡先
- 印字済みの誓約文：「私は、測量成果をそのまま複製し、営利の目的で販売いたしません。」
- 記入表：複製の目的及び利用方法／複製の範囲（図郭番号）／複製する測量成果の種類及び内容／備考
- 事務処理欄（受付・図郭数・提供額合計）は**市が記入するので空欄のまま**

「複製する測量成果の種類及び内容」は `DMフォーマット（地図情報レベル500）` が印字済みのため記入不要。

### 記載内容案

| 欄 | 記載する内容 |
|---|---|
| 日付 | 投函日 |
| 宛先 | 豊中市長　様（印字済み） |
| 住所 | ＿＿＿（申込者本人の住所） |
| 氏名 | ＿＿＿（**個人名**）＋押印 |
| 連絡先 | ＿＿＿（電話番号。記入例は市外局番なしだが、市外在住のため市外局番から記入する） |
| 複製の目的及び利用方法 | 道路台帳DMフォーマットをGeoJSONに変換するツールの動作検証。オープンソースソフトウェアとして公開予定 |
| 複製の範囲（図郭番号） | ＿＿＿（未確定。記入例のように複数記載可） |
| 複製する測量成果の種類及び内容 | DMフォーマット（地図情報レベル500）※印字済み |
| 備考 | 郵送での申込を希望。返信用封筒2枚（納付書用・CD-R用）を同封 |

### 記入上の注意

- 問合せ時に「個人で開発」と伝えているため、**申込者は個人名で統一する**。会社名で出すと照会内容と食い違う
- 記入例では図郭番号を `48-80` `48-90` と2件並べており、複数図郭を1枚の申込書で記載できる
- 様式PDFは平成20年（2008年）版だが、要領は令和3年（2021年）1月1日適用。窓口ページに掲載されているのはこの2008年版のため、これを使う前提。ただし押印の要否と併せて電話で確認する

## 次のアクション

リードタイムが1ヶ月あり、封筒サイズの不備で差し戻されると倍かかる。
申込書を送る前に、**電話で残りの未確認事項をまとめて確認する**。

### 電話で確認する事項

1. 返信用封筒2枚について、それぞれの指定サイズと必要な切手額。特にCD-R送付用はクッション封筒でよいか
2. 申込書（様式1）は令和3年1月1日適用の様式でよいか。押印は必要か
3. 注記や道路構造物の記載が多い図郭の推奨はあるか。こちらの候補は `67-68`
4. 申込書の送付先住所（基盤管理課宛でよいか）
5. 変換結果（GeoJSON）や画面表示例を、GitHubリポジトリや技術記事で公開してよいか。測量成果そのもの（DMファイル）を再配布する予定はない

確認後、図郭を確定して申込書を郵送する。
